## Decisions

### Search (task 1)
- Placement: right-aligned inside the same row as the tab buttons on desktop (visually part of the tab bar, filling the free space on the right);
  on narrow screens it wraps below the tabs at full width. Must not break `TabsTop` for other usages: extend `TabsTop` backward-compatibly
  (e.g. optional slot prop rendered at the end of the tablist row, outside of the `role=tab` buttons, with `ml-auto`) OR place it in the home tile layout
  if that gives the same visual result. Do not change behaviour/visuals of `TabsTop` when the new prop is not used.
- Input: `type="search"`, placeholder "Search components…", `aria-label="Search components"`, search icon, clear (×) button when non-empty; Escape clears.
  Reuse an existing input/search component from `ui/` if one fits; no new libraries.
- Matching: case-insensitive substring on demo display name, demo component/route name and category name (category match returns all its demos).
  Whitespace-trimmed; empty query = normal tab view.
- Results: while the query is non-empty the tile panel shows a results list instead of the selected tab's content:
  each result is a link to the demo route with its display name and a small category label; grouped or sorted by category in `demoList` order.
  "No results for “…”" when empty. Clearing returns to the previously selected tab. Results links behave like existing demo links (client-side navigation).
- Logic in a separate pure function file (e.g. `src/app/demos/demoSearch.ts`) with a unit test in `test/` following existing test conventions.

### Theme switch (task 2)
- In `SiteNavHeader` (desktop and mobile panel) use `ThemeSwitch` from `ui/interactive/theme/ThemeSwitch.tsx`, same usage/props as in `ui/modules/nav_header/NavHeader.tsx`
  (read it, do not import from it). Remove the now-unused `ThemeButton` usage in the site header. Do not edit NavHeader module or demo.
  Site header still must not import from `ui/modules/nav_header/`, `ui/modules/app_sidebar/`, `src/demos/`.
- Fullscreen demo floating controls unchanged.
